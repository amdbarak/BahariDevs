# 10 — Release Plan

## 1. Date reality

Today is **15 June 2026**. The requested date, **20 June 2026**, is five days away.

A complete public website, secure service-management application, commercial-document system, integrations, testing, privacy work, staging, and production hardening cannot responsibly be promised in that window.

## 2. Recommended milestones

### Milestone A — Marketing release target: 20 June 2026

Only attempt this date if assets, hosting, and approvals are immediately available.

Scope:
- hosting/repository preflight;
- project foundation;
- approved design system and public shell;
- priority Home, Services, About, Contact;
- secure contact/lead intake or limited request intake;
- essential SEO;
- privacy/terms drafts clearly pending legal review;
- accessibility/performance pass;
- production deployment, backup, monitoring, and rollback basics.

Exclude from this date:
- full technician operations;
- complex item workflow;
- inbound WhatsApp/email;
- quotes/invoices/receipts;
- analytics dashboards;
- full CMS;
- completed privacy automation.

### Milestone B — Operational beta

Scope:
- guest request and tracking;
- item workflows;
- assignments;
- scheduling;
- private files;
- messaging;
- email notifications;
- admin operations;
- technician portal.

### Milestone C — Commercial and integration release

Scope:
- WhatsApp;
- inbound replies;
- quotes;
- invoices;
- manual payment/receipts;
- CMS depth;
- analytics;
- retention/privacy tooling;
- security and launch audit.

## 3. Task sequence

Tasks 00–24 are authoritative. Tasks may be regrouped into milestones but not skipped.

## 4. Release gates

A release needs:
- owner acceptance;
- green automated tests;
- hosting/staging verification;
- approved content;
- provider credentials where features are enabled;
- privacy/security checklist;
- backup and restore evidence;
- no critical/high unresolved vulnerabilities;
- documented limitations.

## 5. Feature flags

Provider-dependent or incomplete features must be disabled safely:
- WhatsApp;
- inbound replies;
- scheduled publishing if scheduler unverified;
- financial documents pending tax wording;
- analytics pending consent/provider;
- public testimonials/portfolio until real content.

# Hosting Support Request Template

Subject: Laravel 13 application hosting capability confirmation

Hello,

We plan to deploy a Laravel 13 application on this cPanel account. Please confirm the following for the specific hosting package/account:

1. Available PHP CLI and web versions, especially PHP 8.4 or 8.5
2. Ability to select the same PHP version for CLI and web
3. Installed/available extensions:
   - BCMath
   - Ctype
   - cURL
   - DOM/XML
   - Fileinfo
   - GD and/or Imagick
   - Intl
   - JSON
   - Mbstring
   - OpenSSL
   - PDO MySQL
   - Sodium
   - Tokenizer
   - Zip
4. Exact MariaDB version and SQL mode
5. SSH access restrictions
6. Composer availability and version
7. Node.js/npm availability and supported versions
8. Cron-job minimum interval
9. Whether long-running queue workers or process managers are supported
10. Whether a bounded Laravel queue worker may be run from cron
11. Redis availability
12. Ability to set the domain document root directly to Laravel's `/public` directory
13. Symbolic-link support
14. Maximum upload size, POST size, PHP memory, and execution limits
15. Outbound HTTPS/API connectivity to transactional email and Meta APIs
16. Inbound webhook support
17. Staging subdomain/database availability
18. Automated backup frequency, retention, and restore process
19. Malware scanning availability
20. Recommended Laravel deployment method on this platform

Please do not send passwords or credentials in the reply.

Thank you.
